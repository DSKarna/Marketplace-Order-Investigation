# Data attribution and reuse

The raw data is the **Brazilian E-Commerce Public Dataset by Olist**, published by Olist at https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce. Original CSVs in this project were obtained from Olist's public repository: https://github.com/olist/work-at-olist-data/tree/master/datasets.

Olist's dataset is licensed under the Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International license: https://creativecommons.org/licenses/by-nc-sa/4.0/.

The original CSVs are included unmodified. The analysis creates a SQLite database, aggregate CSVs, a chart and a workbook derived from them. Those derived materials and the project documentation are shared under the same CC BY-NC-SA 4.0 terms. When reusing, provide attribution, identify changes, use the materials for noncommercial purposes, and share adaptations under the same license.
